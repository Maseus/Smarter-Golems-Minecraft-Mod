Minecraft mod "Smarter Golems"

A mod that enables the user to set tasks such as farming and maybe other features later.

How it should work. The User places a carved pumpkin on a copper block like usual
but now the user can sneak and right click the golem to set a task instead of the usual behavior

The task that it needs to be able to do first off is farming. in the GUI you select farming and then the copper golem, 
will farm the area in a 9x9 area
